Shortcuts

Scroll = zoom · drag empty space (or middle-drag) = pan · R rotate · Delete remove · Ctrl+Z / Ctrl+Y undo/redo · Ctrl+C copy · Ctrl+V paste · Ctrl+D duplicate · Shift-click multi-select · Shift+drag = box select · Esc cancels a wire. Click a hole or pin, then another, to add a wire. To draw a bent wire click a start hole, click empty space for each corner (Backspace removes the last corner), then click the end hole. Drag a wire to add a bend; drag a bend point to move it; double-click a bend point to remove it. The ❯ tab (or Components) hides the parts panel, and the – button on the part card minimizes it.
